# WangZengqi-Writing-Style

[English README](./README.en.md)

> 不是另一个 `humanizer-zh`。  
> 这是一个专门解决“去掉 AI 味之后，文字还是没有感情、没有人味、没有气口”的中文写作 skill。

## 它解决什么问题

很多中文 humanizer、去 AI 味 prompt、润色 skill，确实能处理掉这些东西：

- 模板腔
- 排比腔
- 过度总结
- “首先其次最后”式结构
- 一眼能看出来的 ChatGPT 词汇习惯

但处理完以后，常常还会剩下一个更难的问题：

**文字不假了，但还是空。**

它像人说话，却不像一个真正活过、看过、爱过、记得住细节的人在写。

常见症状是：

- 句子顺了，但没有情感着力点
- 词更自然了，但没有人物和风物
- 看起来“像中文”，但没有气口，没有回味
- 去掉了 AI 味，却没有长出作者自己的味道

这个仓库里的 skill，就是为这个问题做的。

它不靠“替换几个更自然的词”，而是借汪曾祺的写作机制，把一段文字往这几个方向推：

- 更有人物
- 更有细节
- 更有风物
- 更有生活质地
- 更有句群之间的行气
- 更克制，但也更有感情

一句话说，它解决的不是“像不像 AI 写的”，而是：

**这段话像不像一个真正有生活的人写的。**

## 为什么普通 humanizer 不够

大多数 humanizer skill 的强项，是做“表层去 AI 化”：

- 换词
- 打散结构
- 降低模板感
- 避开高频 AI 句式

这些都重要，但它们只解决了第一层问题。

真正难的是第二层：

1. 感情落在哪里
2. 细节从哪里长出来
3. 一个句子怎么和下一个句子接上气
4. 什么该说，什么不该说破
5. 怎么写“平常”，但不写成“平”

汪曾祺提供的不是“文艺化表达”，而是一整套更深的写作机制：

- `贴着人物写`
- `情感寄存在风物细节里`
- `平淡而有行气`
- `汉语要雅俗互养`
- `语言不是包装，而是内容本身`

所以这个项目更像是：

**humanizer 的下一层。**

不是把文章“修得像人”，而是把文章“写得更有人”。

## 这个 skill 是怎么工作的

这个 skill 不会一上来就替你“美化语言”。

它会先按汪曾祺式写法，去看一段文字最根本的问题：

### 1. 看对象和风物

- 写的是谁
- 在什么地方
- 在什么时节
- 有没有可以抓住的吃食、器物、草木、街巷、天气

### 2. 看人物和关系

- 这段文字里有没有人
- 人与人之间有没有动作、称呼、习惯
- 作者是不是说得太多，人物自己活得太少

### 3. 看语言行气

- 句子是不是太整齐
- 有没有信息堆砌
- 有没有“看起来顺，但没有流动感”的问题

### 4. 看情感分寸

- 情绪是不是直接喊出来了
- 能不能把情绪挪到景、物、动作、停顿里

然后它才会开始改写。

所以它的目标不是“润色”，而是**重建一段文字的情感结构和气口**。

## 为什么值得用它来写作

如果你已经试过很多中文写作 skill，你会发现一个分水岭：

- 前一类工具让文字更像“写得不错”
- 后一类工具让文字更像“有人在里面”

这个 skill 属于后者。

它特别适合下面这些场景：

- 你写公众号、长帖、视频文案，想去掉浓重 AI 味
- 你写自媒体故事、回忆、人物小传，想让文字更有情味
- 你在做 AI 写作产品，想验证“去 AI 味”之后还能不能再往前走一步
- 你已经有 `humanizer-zh` 一类 skill，但想解决“自然了，还是不动人”的问题
- 你希望一段文字不是更花，而是更活

它不追求把每段话都改成“汪曾祺原文风”。

它真正有价值的地方，是教会 agent 在改稿时优先做这些事：

- 留住值得保留的生活材料
- 找到真正该写的细节
- 删掉多余解释和空泛抒情
- 让感情落在东西上，而不是落在口号上

### 方式 2：和 `humanizer-zh` 串联使用

推荐工作流：

1. 先用 `humanizer-zh` 去掉明显模板感和 AI 腔
2. 再用这个 skill 处理“没有情感、没有人味、没有气口”的问题

一个典型串联 prompt：

```text
先用 humanizer-zh 去掉明显 AI 味，再用 wang-zengqi-perspective 重写：
1. 保留原意
2. 增加人物、风物、细节
3. 不要喊情绪，让情绪落在景和动作里
4. 句子要平淡，但要有行气
```

## 示例：它会把文字往什么方向改

它不鼓励把一句普通话改得花里胡哨。

它更偏向这种变化：

### Before

> 那天我回到老家，内心非常感慨。时间过去了很多年，但故乡的一切依然让我觉得温暖。

### After

> 车进镇口的时候，先看见那家卖烧饼的铺子。炉子还是摆在门外，火不大，芝麻香倒还是老样子。街比从前宽了一点，人少了。我下车站了一会儿，才想起来，原来我已经很多年没有这样走回来了。

重点不是“更华丽”，而是：

- 感慨不直接喊出来
- 温暖不直接宣布
- 情绪落在铺子、炉火、芝麻香、街面和停顿上

## 研究方法

这个 skill 不是凭印象拼出来的“文风 prompt”。

它基于对汪曾祺以下材料的聚焦提炼：

- 文论与写作自述
- 自报家门式自我说明
- 关于语言、短篇本质、虚构来源的公开文字
- 高质量研究文章与评论
- 时间线、创作选择、风格演化的交叉整理

最终提炼出的不是“像不像汪曾祺说话”，而是：

- 他如何观察
- 他如何处理人物
- 他如何安放情绪
- 他如何让平常句子产生味道

## 边界与不适用场景

这个 skill 很有用，但不是万能的。

它不适合：

- 纯学术论文
- 法律、合同、合规文本
- 强结构化商业汇报
- 需要高密度信息压缩的技术说明书

它也不能替代：

- 真实生活经验
- 作者自己的观察力
- 长期写作训练

如果原文里完全没有人物、场景、细节、动作、关系，再强的 skill 也只能有限改善。
